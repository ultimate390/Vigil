## 🚀 Что это

**Vigil** — лёгкий, но серьёзный менеджер процессов в духе Process Hacker / AnVir Task Manager,
написанный на чистом Python. Смотрит за процессами, службами, автозапуском и здоровьем системы —
и делает это понятно даже для обычного пользователя. 🧠

## ✨ Возможности

### ⚙️ Процессы
- 🖼️ Иконки приложений + 🎨 подсветка «прожорливых» и приостановленных
- 🚦 Уровень риска в **%** (по пути, расположению и издателю)
- 🧾 Описание и издатель файла, поиск, сортировка, автообновление
- 🔎 Панель деталей: инфо · производительность · потоки · соединения · файлы · **модули (DLL)**
- 💀 Завершить / убить / убить дерево / перезапустить · ⏸️ приостановить · 🎚️ приоритет · 🧵 affinity
- #️⃣ Хеши (MD5/SHA-1/SHA-256) · ✍️ проверка цифровой подписи

### 🛡️ Безопасность
- 🧪 Проверка файла на **VirusTotal** в один клик (по SHA-256)
- 🌐 «Что это за процесс?» — поиск в интернете
- ⚠️ Флаг запусков из Temp / AppData / Downloads

### 🚦 Автозапуск, службы, лог
- 🗂️ Реестр Run/RunOnce/Winlogon · папка автозагрузки · планировщик · драйверы
- 🧩 Службы Windows: старт / стоп / пауза / тип запуска
- 📜 **Лог активности** — что запускалось и закрывалось (с датой/временем, **сохраняется на диск**)

### 📟 Мини-монитор в углу экрана
Маленький виджет поверх всех окон: 🌡️ температура ЦП · 💽 загрузка диска · 🧠 память · ⚙️ CPU

### 🎨 Оформление
🌗 Тёмная/светлая темы · 🌍 5 языков (RU / EN / UK / DE / ES) · 📈 живой график CPU · иконки везде

## 📦 Установка

```bash
pip install psutil
# по желанию — иконки приложений, описания файлов, температура ЦП:
pip install pillow pywin32

python main.py   # лучше от имени администратора 🔑
```

## 🏗️ Сборка в .exe

```bash
pip install pyinstaller psutil pillow pywin32
python -m PyInstaller --onefile --noconsole --uac-admin --icon=icon.ico --name Vigil main.py
# → dist\Vigil.exe
```
